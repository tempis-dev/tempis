Simple, flexible timeline for the web

A lightweight, canvas-rendered timeline library with smooth interactions, touch support, and zero dependencies.

Get Started GitHub
🎨

Canvas Rendered

High-performance HTML5 Canvas rendering handles thousands of items smoothly with no DOM overhead.

📱

Touch Ready

First-class touch support with pinch-to-zoom, smooth panning, and responsive layouts out of the box.

🪶

Zero Dependencies

No external runtime dependencies. Just a single lightweight bundle that works everywhere.

⚡

Animated Focus

Smoothly animate to items, dates, or ranges with configurable easing and duration.

🏷️

Categories & Groups

Organize items with categories and groups. Filter via an interactive legend with highlight on hover.

🔌

Date Adapter

Pluggable date adapter system. Use the built-in native adapter or bring your own (Luxon, Day.js, etc.).

Get started in seconds

$ npm install tempis-timeline
