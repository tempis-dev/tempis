Get Started

Up and running with Tempis Timeline in a few minutes.

Installation

npm

npm install tempis-timeline

CDN

Include the script directly in your HTML:

<script src="https://unpkg.com/tempis-timeline/dist/tempis_timeline.min.js"></script>

Basic Usage

Create a canvas element and initialize the timeline:

<div style="width: 100%; height: 400px;">
  <canvas id="timeline"></canvas>
</div>

<script>
  const timeline = new TempisTimeline('#timeline', {
    responsive: true,
    verticalFill: 'fill-canvas',
    items: [
      {
        id: 1,
        label: 'Project Kickoff',
        start: '2024-01-15T09:00:00',
        end: '2024-01-15T11:00:00'
      },
      {
        id: 2,
        label: 'Design Review',
        start: '2024-01-15T13:00:00',
        end: '2024-01-15T15:30:00'
      },
      {
        id: 3,
        label: 'Deployment',
        start: '2024-01-15T16:00:00'  // Point-in-time item (no end date)
      }
    ]
  });
</script>

Adding Categories

Categories let you color-code and filter items via an interactive legend:

const timeline = new TempisTimeline('#timeline', {
  responsive: true,
  verticalFill: 'fill-canvas',
  legend: { position: 'top' },
  categories: [
    { name: 'meeting', label: 'Meetings', style: { backgroundColor: '#4caf50', fontColor: '#fff' } },
    { name: 'deadline', label: 'Deadlines', style: { backgroundColor: '#f44336', fontColor: '#fff' } }
  ],
  items: [
    { id: 1, label: 'Sprint Planning', start: '2024-01-15T09:00:00', end: '2024-01-15T10:00:00', category: 'meeting' },
    { id: 2, label: 'Release v2.0', start: '2024-01-15T17:00:00', category: 'deadline' }
  ]
});

Groups

Use the grouping property to organize items into rows:

items: [
  { id: 1, label: 'Task A', start: '2024-01-15T09:00:00', end: '2024-01-15T11:00:00', grouping: 'Team Alpha' },
  { id: 2, label: 'Task B', start: '2024-01-15T10:00:00', end: '2024-01-15T12:00:00', grouping: 'Team Beta' },
  { id: 3, label: 'Task C', start: '2024-01-15T13:00:00', end: '2024-01-15T15:00:00', grouping: 'Team Alpha' }
]

Selection

Enable item selection with the selection option:

const timeline = new TempisTimeline('#timeline', {
  selection: 'single', // or 'multi' or 'none'
  onSelectionChange(changes) {
    console.log('Selection changed:', changes);
  },
  items: [...]
});

Updating Data

Update items dynamically at any time:

// Replace all items
timeline.setItems(newItems);

// Update categories
timeline.setCategories(newCategories);

// Update bands
timeline.setBands(newBands);

Focus & Navigation

Programmatically navigate the timeline:

// Animate to a specific item
timeline.focus({ id: 'item-1', animate: true, duration: 500 });

// Jump to a date
timeline.focus({ date: '2024-06-15', animate: false });

// Focus on a date range
timeline.focus({ range: ['2024-01-01', '2024-12-31'], animate: true });

Cleanup

Always destroy the timeline when you're done to prevent memory leaks:

timeline.destroy();
