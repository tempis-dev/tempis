Examples

Interactive demos showcasing different features and use cases.

Featured

🎮 Playground

Interactive testing environment with controls for all timeline options. Adjust layout, styling, data, and behavior in real-time.

📡 Crypto Price Stream

Live cryptocurrency prices via WebSocket. Demonstrates real-time data updates with color-coded price movements.

🏭 Production Downtime

Downtime tracking with selection-driven detail panels. Shows animated layout transitions and controlled selection.

🔄 Lazy Loading

Server request logs loaded on demand as you pan. Demonstrates onRangeChange with debounced fetching and caching.

💬 Custom Tooltips

Project sprint tracker with rich tooltip cards showing assignee details, status, priority, and progress bars.

🌍 Timezone Explorer

Global flight schedule using a custom Luxon-based date adapter. Switch timezones and watch the timeline re-render in different local times.

📊 Server Monitoring

Weekly Kubernetes cluster overview with bands for maintenance windows, off-peak hours, deployment markers, and incident lines.

🌐 RTL Project Schedule

Arabic mobile app development schedule with full right-to-left support. Toggle between RTL and LTR to compare layouts.

🎨 Color Palettes

Switch between curated color palettes and watch the timeline update instantly. Demonstrates the global palette API for theming.

📋 External Selection

Click rows in an event grid to select and focus items on the timeline. Demonstrates programmatic selection driven entirely from outside the canvas.

📸 Export to Image

Music festival schedule across 5 stages over a weekend. Pick format, quality, and DPR then download the timeline as an image via toImage().

🎬 Per-Item Styles

Film production schedule with per-item style overrides. Blocked tasks, completed work, at-risk items, and milestones each get unique visual treatment.

⌨️ Keypress Timeline

Keyboard event visualization. Short presses create point-in-time items, long presses create live-updating range items.
