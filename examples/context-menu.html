onItemContextClick Callback
The onItemContextClick(id, position) callback fires when a user right-clicks a timeline item. It provides the item id and viewport coordinates ({ x, y }) so you can position a custom menu. The browser's default context menu is automatically suppressed when the callback is provided and the click lands on an item.
