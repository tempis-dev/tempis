Styling

Customise the look of the timeline, items, and text.

TempisTimelineStyleOptions

PropertyTypeDescription
fontTempisTimelineFontDefault font settings (size, family, style, weight, lineHeight).
itemTempisTimelineItemStyleDefault item style overrides applied to all items.

TempisTimelineItemStyle

PropertyTypeDefaultDescription
backgroundColorstringpalette colourItem background colour.
fontColorstring—Item label colour.
paddingnumber—Inner padding in pixels.
borderColorstring—Border colour.
borderThicknessnumber—Border width in pixels.
borderStylestring"solid"One of: solid, dashed, dotted, dash-dot, long-dash.
borderRadiusnumber—Corner radius in pixels.

Style Precedence

Styles are resolved in the following order (highest priority first):

  1. Per-item style on the item object.
  2. Category style from the matching category.
  3. Global style.item from the constructor options.
  4. Library defaults.

Example — Dark Theme

const timeline = new TempisTimeline('#canvas', {
  responsive: true,
  style: {
    font: { family: 'Inter, sans-serif', size: 13, weight: 500 },
    item: {
      backgroundColor: '#334155',
      fontColor: '#f1f5f9',
      borderColor: '#475569',
      borderThickness: 1,
      borderStyle: 'solid',
      borderRadius: 6,
      padding: 6
    }
  },
  items: [
    { id: 1, label: 'Research',    start: '2026-01-05', end: '2026-01-15' },
    { id: 2, label: 'Development', start: '2026-01-12', end: '2026-01-28' },
    {
      id: 3, label: 'Urgent Fix', start: '2026-01-20', end: '2026-01-22',
      style: { backgroundColor: '#dc2626', borderStyle: 'dashed' }
    },
  ],
  range: { start: '2026-01-01', end: '2026-02-01', position: 'bottom' }
});
