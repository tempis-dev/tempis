RTL

Right-to-left rendering for languages like Arabic and Hebrew.

Option

PropertyTypeDefaultDescription
rtlbooleanfalseEnable right-to-left layout.

What Changes

  • The time axis flows from right (earliest) to left (latest).
  • Item labels and grouping labels are right-aligned.
  • The legend renders in RTL order.
  • Default tooltips use RTL text direction.
  • Dependency connector arrows are reversed (source left edge → target right edge).
  • Keyboard navigation is reversed (Arrow Right pans backward in time).
  • The minimap viewport indicator and item positions are mirrored.
  • The progress fill renders from the right edge.

Example

const timeline = new TempisTimeline('#canvas', {
  responsive: true,
  rtl: true,
  items: [
    { id: 1, label: '\u062A\u0635\u0645\u064A\u0645',  start: '2026-01-05', end: '2026-01-15', grouping: '\u0627\u0644\u0641\u0631\u064A\u0642 \u0623' },
    { id: 2, label: '\u062A\u0637\u0648\u064A\u0631',  start: '2026-01-12', end: '2026-01-28', grouping: '\u0627\u0644\u0641\u0631\u064A\u0642 \u0623' },
    { id: 3, label: '\u0627\u062E\u062A\u0628\u0627\u0631', start: '2026-01-20', end: '2026-02-05', grouping: '\u0627\u0644\u0641\u0631\u064A\u0642 \u0628' },
  ],
  range: { start: '2026-01-01', end: '2026-02-15', position: 'bottom' }
});
