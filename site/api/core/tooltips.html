Tooltips

Show contextual information when hovering over timeline items.

Hover over items to see custom tooltips.

The default tooltip shows the item label and date range. Provide a template function to fully customise the content.

TempisTimelineTooltipOptions

PropertyTypeDefaultDescription
enabledbooleantrueEnable or disable tooltips globally.
delaynumber0Delay in milliseconds before the tooltip appears.
dateFormatstring"D MMMM HH:mm:ss"Date format pattern for the default tooltip.
overflowBehavior"none" | "canvas" | "viewport""none"How the tooltip repositions near edges.
template(id) => HTMLElement | string | null—Custom template function. Return an HTML string or element.
shouldShow(id) => boolean—Predicate controlling whether a tooltip appears for a given item.

The overflowBehavior options are:

  • "none" — no repositioning; the tooltip may be clipped.
  • "canvas" — the tooltip flips to stay within the canvas bounds.
  • "viewport" — the tooltip flips to stay within the browser viewport.

Custom Template

The template function receives the item ID and should return an HTML string or HTMLElement. Return null to fall back to the default tooltip.

const timeline = new TempisTimeline('#canvas', {
  items: [
    { id: 1, label: 'Item 1', start: '2026-04-10', end: '2026-04-12' },
  ],
  range: { start: '2026-04-01', end: '2026-04-30', position: 'bottom' },
  tooltip: {
    overflowBehavior: 'viewport',
    template(id) {
      const item = timeline.getItems().find(i => i.id === id);
      return `
        <div style="padding: 8px; font-family: sans-serif;">
          <strong>${item?.label}</strong>
          <p style="margin: 4px 0 0;">Custom tooltip content</p>
        </div>
      `;
    }
  }
});

shouldShow Predicate

Use shouldShow to conditionally suppress tooltips for specific items.

tooltip: {
  shouldShow(id) {
    // Only show tooltips for items with id > 10
    return typeof id === 'number' && id > 10;
  }
}
