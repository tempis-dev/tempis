Dependencies

Render connector arrows between items to show relationships.

TempisTimelineDependency

PropertyTypeDescription
sourcestring | numberThe ID of the source item (arrow starts here).
targetstring | numberThe ID of the target item (arrow points here).

Dependencies are defined separately from items as an array of source → target pairs. Each renders a connector arrow from the right edge of the source item to the left edge of the target item.

Usage

import { TempisTimeline } from '@tempis/timeline';

const timeline = new TempisTimeline('#canvas', {
  responsive: true,
  items: [
    { id: 1, label: 'Item 1', start: '2026-01-05', end: '2026-01-12' },
    { id: 2, label: 'Item 2', start: '2026-01-13', end: '2026-01-20' },
    { id: 3, label: 'Item 3', start: '2026-01-15', end: '2026-01-28' },
    { id: 4, label: 'Item 4', start: '2026-01-29', end: '2026-02-05' },
  ],
  dependencies: [
    { source: 1, target: 2 },
    { source: 1, target: 3 },
    { source: 2, target: 4 },
    { source: 3, target: 4 },
  ],
  range: { start: '2026-01-01', end: '2026-02-10', position: 'bottom' }
});

Methods

setDependencies(dependencies)

Replaces all dependencies and redraws. Does not affect item layout — only the connector arrows are updated.

timeline.setDependencies([
  { source: 1, target: 2 },
  { source: 2, target: 3 },
]);

Connector Routing

Arrows are routed automatically based on item positions:

  • When the target is to the right of the source with enough space, a step connector is used (horizontal → vertical → horizontal).
  • When items overlap horizontally, an S-shaped connector routes around both items.
  • All corners are rounded.
  • RTL layouts are fully supported — arrows reverse direction automatically.

RTL Support

In RTL mode, connectors route from the source's left edge to the target's right edge, with arrowheads pointing left.
