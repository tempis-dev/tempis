Categories

Colour-code items and filter them via an interactive legend.

Category Interface

PropertyTypeDescription
namestringUnique identifier referenced by items.
labelstringDisplay label in the legend.
styleTempisTimelineItemStyleStyle applied to all items in this category.
 
const timeline = new TempisTimeline('#canvas', {
  categories: [
    { name: 'dev',    label: 'Development', style: { backgroundColor: '#6366f1', fontColor: '#fff' } },
    { name: 'design', label: 'Design',      style: { backgroundColor: '#f43f5e', fontColor: '#fff' } },
    { name: 'qa',     label: 'QA',          style: { backgroundColor: '#10b981', fontColor: '#fff' } },
  ],
  legend: { position: 'top' },
  items: [
    { id: 1, label: 'Auth Module', start: '2026-02-01', end: '2026-02-14', category: 'dev' },
    { id: 2, label: 'Wireframes',  start: '2026-02-05', end: '2026-02-12', category: 'design' },
    { id: 3, label: 'Unit Tests',  start: '2026-02-10', end: '2026-02-20', category: 'qa' },
  ],
  range: { start: '2026-01-25', end: '2026-03-01', position: 'bottom' }
});

Methods

setCategories(categories)

Replaces all categories and redraws.

getCategories()

Returns the current category definitions.

Colour Palette

Categories without an explicit backgroundColor are assigned colours from the global palette. See Color Palette.
