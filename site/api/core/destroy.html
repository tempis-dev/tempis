destroy()

Clean up a timeline instance and release all resources.

Method

timeline.destroy();

What It Cleans Up

  • All pointer, wheel, mouse, and double-click event listeners on the canvas.
  • The ResizeObserver watching the canvas container (when responsive is enabled).
  • Any in-progress focus or scroll animations.
  • The tooltip DOM element and its event listeners.
  • The legend DOM element and its event listeners.
  • The canvas is cleared.

When to Call It

Call destroy() before removing the canvas from the DOM or when the timeline is no longer needed. This prevents memory leaks from orphaned listeners and observers.

In frameworks like React, the <TempisTimeline> component handles this automatically on unmount. You only need to call destroy() when managing the core library directly.

// Create
const timeline = new TempisTimeline('#canvas', { items: [...] });

// Later, when done
timeline.destroy();
