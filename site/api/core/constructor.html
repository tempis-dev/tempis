Creating a Timeline

Create a new timeline instance.

Constructing a timeline renders it immediately, attaches the canvas event listeners, and (with responsive: true) starts a ResizeObserver on the parent. Call destroy() before the canvas leaves the DOM to release all of these.

new TempisTimeline(context: string | HTMLCanvasElement, options: TempisTimelineOptions)

The context parameter accepts either a CSS selector string pointing to a <canvas> element, or a direct reference to one. items is the only required option.

Minimal Example

import { TempisTimeline } from '@tempis/timeline';

const timeline = new TempisTimeline('#timeline', {
  responsive: true,
  range: { start: '2026-01-01', end: '2026-02-01', position: 'bottom' },
  items: [
    { id: 1, label: 'Discovery', start: '2026-01-05', end: '2026-01-15', grouping: 'Phase 1' },
    { id: 2, label: 'Build',     start: '2026-01-12', end: '2026-01-28', grouping: 'Phase 1' },
    { id: 3, label: 'Launch',    start: '2026-01-30',                    grouping: 'Phase 1' }
  ]
});

// Pass an element reference instead of a selector if you prefer.
const canvas = document.getElementById('timeline') as HTMLCanvasElement;
const timeline2 = new TempisTimeline(canvas, { items: [] });

When using responsive: true, the canvas must be inside a container with explicit dimensions. The timeline resizes to fill its parent. If the parent has no width or height, the canvas will collapse to zero.

destroy()

Removes the canvas event listeners, disconnects the resize observer, cancels in-flight animations, tears down the tooltip and legend views, and clears the canvas. Call it before the canvas leaves the DOM; otherwise the listeners and observer keep the instance alive.

timeline.destroy();

The React and Vue components call this for you on unmount.
