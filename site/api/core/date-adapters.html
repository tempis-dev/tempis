Date Adapters

Plug in custom date libraries for timezone and locale support.

TempisTimelineDateAdapter

A date adapter must implement four methods:

MethodSignatureDescription
parse(input: DateInput) => number | nullParse a Date, ISO string, or timestamp into epoch milliseconds.
startOf(instant: number, unit: Unit) => numberSnap a timestamp to the start of the given unit.
add(instant: number, unit: Unit, amount: number) => numberAdd calendar units to a timestamp.
format(instant: number, pattern: string) => stringFormat a timestamp using a pattern string.

Registering an Adapter

import { TempisTimeline } from '@tempis/timeline';

TempisTimeline.registerDateAdapter(myAdapter);

Internally this calls AdapterRegistry.register(). If no adapter is registered, a built-in NativeDateAdapter using the browser's Date and Intl APIs is used automatically.

Built-in Native Adapter

The default adapter works with the local timezone and supports standard format tokens. No installation required — it is used out of the box.

Example — Luxon Adapter Skeleton

import { DateTime } from 'luxon';
import { TempisTimeline } from '@tempis/timeline';
import type { TempisTimelineDateAdapter } from '@tempis/timeline';

const luxonAdapter: TempisTimelineDateAdapter = {
  parse(input) {
    if (input instanceof Date) return input.getTime();
    if (typeof input === 'number') return input;
    const dt = DateTime.fromISO(input, { zone: 'America/New_York' });
    return dt.isValid ? dt.toMillis() : null;
  },
  startOf(instant, unit) {
    return DateTime.fromMillis(instant, { zone: 'America/New_York' })
      .startOf(unit).toMillis();
  },
  add(instant, unit, amount) {
    return DateTime.fromMillis(instant, { zone: 'America/New_York' })
      .plus({ [unit + 's']: amount }).toMillis();
  },
  format(instant, pattern) {
    return DateTime.fromMillis(instant, { zone: 'America/New_York' })
      .toFormat(pattern);
  }
};

TempisTimeline.registerDateAdapter(luxonAdapter);
