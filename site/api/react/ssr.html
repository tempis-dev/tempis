SSR & Next.js

Safely render the timeline in server-side rendering environments.

SSR Guard

The <TempisTimeline> component includes a built-in SSR guard. During server-side rendering (when window is undefined), the component renders the canvas element but skips timeline initialisation. The core instance is created only on the client after mount.

Next.js — Dynamic Import

In Next.js, use next/dynamic with ssr: false to ensure the component is only loaded on the client. This avoids any server-side import of canvas-dependent code.

import dynamic from 'next/dynamic';

const TempisTimeline = dynamic(
  () => import('@tempis/react').then(mod => mod.TempisTimeline),
  { ssr: false }
);

export default function Page() {
  return (
    <TempisTimeline
      items={[
        { id: 1, label: 'Item 1', start: '2026-01-05', end: '2026-01-19' },
        { id: 2, label: 'Item 2', start: '2026-01-20', end: '2026-02-02' },
      ]}
      options={{
        responsive: true,
        range: { start: '2026-01-01', end: '2026-02-15', position: 'bottom' }
      }}
      height={400}
    />
  );
}
