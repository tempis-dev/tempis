API Reference

Complete reference for the Tempis Timeline API.

Constructor

new TempisTimeline(context: string | HTMLCanvasElement, options: TempisTimelineOptions)

Creates a new timeline instance. The context can be a CSS selector string or a canvas element reference.

Methods

setItems(items)

Replaces all timeline items and redraws.

timeline.setItems([
  { id: 1, label: 'Event', start: '2024-01-15T09:00:00', end: '2024-01-15T11:00:00' }
]);

getItems()

Returns the current item definitions as last provided via the constructor or setItems().

const items = timeline.getItems();

setCategories(categories)

Replaces all categories and redraws.

timeline.setCategories([
  { name: 'task', label: 'Tasks', style: { backgroundColor: '#4caf50' } }
]);

getCategories()

Returns the current category definitions as last provided via the constructor or setCategories().

const categories = timeline.getCategories();

setBands(bands)

Replaces all timeline bands and redraws.

timeline.setBands([
  { start: '2024-01-15T12:00:00', end: '2024-01-15T13:00:00', style: { color: '#ff0000', opacity: 0.1 } }
]);

focus(options?)

Navigates the timeline to a specific item, date, or range.

// Focus on an item
timeline.focus({ id: 'item-1', animate: true, duration: 500 });

// Focus on a date
timeline.focus({ date: '2024-06-15' });

// Focus on a range
timeline.focus({ range: ['2024-01-01', '2024-12-31'], animate: true });

getRange()

Returns the current visible range as { start: Date, end: Date }.

getSelection()

Returns an array of selected item IDs.

setSelection(ids)

Programmatically selects items by their IDs. Deselects all currently selected items first. Works regardless of the selection mode, including "none".

timeline.setSelection([1, 2, 3]);

clearSelection()

Deselects all items and redraws.

timeline.clearSelection();

redraw()

Forces a redraw of the timeline.

destroy()

Removes all event listeners, disconnects observers, and cleans up resources. Always call this before removing the timeline from the DOM.

toImage(options?)

Exports the current timeline view as an image Blob. Returns a Promise<Blob> that resolves with the encoded image data. The canvas is re-rendered before capture to ensure the exported image reflects the latest timeline state. Throws an Error if called after destroy().

// Export as PNG (default)
const blob = await timeline.toImage();
const url = URL.createObjectURL(blob);

// Export as JPEG with quality
const jpegBlob = await timeline.toImage({
  type: 'image/jpeg',
  quality: 0.85
});

// Export at 2× resolution for high-DPI displays
const hiResBlob = await timeline.toImage({ dpr: 2 });

Image Options

Options accepted by toImage() via the ImageGenerationOptions interface.

Static Methods

TempisTimeline.registerDateAdapter(adapter)

Register a custom date adapter for date formatting. The adapter must implement the TempisTimelineDateAdapter interface. If no adapter is registered, the built-in native Date adapter is used.

TempisTimeline.registerDateAdapter(myLuxonAdapter);

TempisTimeline.getDateAdapter()

Returns the currently registered date adapter.

TempisTimeline.setGlobalPalette(palette)

Set the global color palette used for categories that don't specify an explicit backgroundColor. Call setCategories() after changing the palette to apply the new colors to existing instances.

TempisTimeline.setGlobalPalette(['#ff3366', '#0088ff', '#00cc66', '#ffcc00']);

TempisTimeline.getGlobalPalette()

Returns the current global color palette as an array of color strings.
