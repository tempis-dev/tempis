React API Reference

API reference for the @tempis/react wrapper component.

Install

npm install @tempis/react @tempis/timeline

Component

import { TempisTimeline } from '@tempis/react';

Props (TempisTimelineProps)

PropTypeDescription
itemsTempisTimelineItem[]Timeline items (required).
categoriesTempisTimelineCategory[]Item categories.
bandsTempisTimelineBand[]Timeline bands.
optionsTempisTimelineConfigConfiguration options. Changes trigger instance recreate.
onItemClick(id: string | number) => voidCalled when an item is clicked.
onItemDoubleClick(id: string | number) => voidCalled when an item is double-clicked.
onItemHover(id: string | number | null) => voidCalled when pointer enters/leaves an item.
onSelectionChange(changes: SelectionChangeEvent[]) => voidCalled when selection changes.
onRangeChange(start: Date, end: Date) => voidCalled when visible range changes.
classNamestringCSS class for wrapper div.
wrapperStyleCSSPropertiesInline styles for wrapper div.
widthstring | numberCanvas width.
heightstring | numberCanvas height.

Options (TempisTimelineConfig)

PropertyTypeDescription
responsivebooleanResize canvas to match parent.
verticalFill"content" | "fill-canvas" | "grow-canvas"Vertical fill mode.
rtlbooleanRight-to-left rendering.
stackMode"compact" | "stable"Item stacking mode.
selection"none" | "single" | "multi"Selection mode.
rangeTempisTimelineRangeOptionsRange configuration.
legendTempisTimelineLegendOptionsLegend configuration.
tooltipTempisTimelineTooltipOptionsTooltip configuration.
styleTempisTimelineStyleOptionsStyle overrides.
scrollbarTempisTimelineScrollbarOptionsScrollbar options.
groupingTempisTimelineGroupingOptionsGrouping options.

Ref API (TempisTimelineRef)

MethodDescription
focus(options?)Navigate to item, date, or range.
getRange()Get visible range.
setItems(items)Replace all items.
getItems()Get current items.
setCategories(categories)Replace categories.
getCategories()Get current categories.
setBands(bands)Replace bands.
setSelection(ids)Select items by ID.
getSelection()Get selected IDs.
clearSelection()Clear selection.
toImage(options?)Export as image blob.
redraw()Force redraw.
getInstance()Access core instance.
getCanvas()Access canvas element.

Ref Usage Example

import { useRef } from 'react';
import { TempisTimeline, type TempisTimelineRef } from '@tempis/react';

function App() {
  const ref = useRef<TempisTimelineRef>(null);
  return (
    <>
      <button onClick={() => ref.current?.focus({ id: 1, animate: true })}>Focus</button>
      <TempisTimeline ref={ref} items={items} />
    </>
  );
}
